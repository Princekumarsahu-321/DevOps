# 🚀 DevOps Learning Journey

Welcome to my **DevOps Learning Repository**! This repository documents my journey of learning DevOps tools, technologies, concepts, and hands-on projects, from beginner to advanced level.

My goal is to build practical skills in automation, cloud infrastructure, containerization, CI/CD, monitoring, and Kubernetes deployment.

## 🎯 Learning Objectives

- Understand Linux commands and system administration.
- Learn Git and GitHub for version control.
- Containerize applications using Docker.
- Manage multi-container applications using Docker Compose.
- Build CI/CD pipelines using GitHub Actions and Jenkins.
- Learn Infrastructure as Code (IaC) using Terraform.
- Explore AWS cloud services and infrastructure.
- Deploy and manage applications using Kubernetes.
- Monitor application performance using Prometheus and Grafana.
- Practice DevOps through real-world projects.

## 📚 Learning Roadmap

### 1. Linux & Networking
- Linux commands and file permissions
- Users, groups, and process management
- Package management and shell scripting
- IP addresses, DNS, ports, and SSH

### 2. Git & GitHub
- Git fundamentals and branching
- Commits, merges, and pull requests
- Repository management
- Collaboration and version control

### 3. Docker & Docker Compose
- Images, containers, and Dockerfiles
- Docker volumes and networks
- Building custom images
- Running multi-container applications
- Containerizing MERN stack projects

### 4. CI/CD Automation
- Continuous Integration and Continuous Delivery
- GitHub Actions workflows
- Automated testing and builds
- Docker image builds and deployments
- Introduction to Jenkins pipelines

### 5. AWS Cloud
- IAM users, roles, and policies
- EC2 instances and security groups
- S3 storage
- VPC and networking fundamentals
- ECR for container image storage
- Cloud cost monitoring and security

### 6. Terraform
- Infrastructure as Code fundamentals
- Providers, resources, and variables
- Outputs, state, and modules
- Provisioning AWS infrastructure
- `terraform init`, `plan`, `apply`, and `destroy`

### 7. Kubernetes
- Pods, Deployments, and Services
- ConfigMaps and Secrets
- Namespaces and scaling
- Health checks and resource limits
- Application deployment using Minikube

### 8. Monitoring & Observability
- Prometheus metrics and scraping
- PromQL queries
- Grafana dashboards
- Alert rules and notifications
- Monitoring application and system resources
